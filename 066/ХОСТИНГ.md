# Как бесплатно выложить приложение в интернет (работает в России)

## Сначала главное

Это приложение собирается в **один самодостаточный файл** `dist/index.html` — внутри уже
встроены все скрипты и стили. Ему не нужен сервер, база данных и Node.js на хостинге.
Подойдёт любой бесплатный статический хостинг.

Три варианта по возрастанию сложности:

| Вариант | Что нужно | Время |
|---|---|---|
| 1. Вообще без хостинга (офлайн) | ничего | 10 секунд |
| 2. Netlify Drop | браузер, перетащить папку | 2 минуты |
| 3. GitHub Pages | аккаунт GitHub | 5 минут |

---

## Вариант 1. Без хостинга — работает даже без интернета ✅

В приложении есть кнопка **«📦 Офлайн-копия»**. Нажмите её — скачается файл
`066у-приложение.html` с полностью рабочей программой внутри.

- Откройте файл двойным щелчком в любом браузере — приложение работает.
- Можно скопировать на флешку, переслать в мессенджере, положить в сетевую папку больницы.
- Интернет нужен **только один раз**, чтобы открыть сайт и скачать файл. Дальше — никак.

Это идеальный вариант для рабочего компьютера в медицинской организации, где доступ
к внешним сайтам часто ограничен.

---

## Вариант 2. Netlify Drop — без регистрации и без git

1. Соберите проект на своём компьютере:
   ```
   npm install
   npm run build
   ```
   Появится папка `dist` с одним файлом `index.html`.
2. Откройте https://app.netlify.com/drop
3. Перетащите **папку `dist`** в окно браузера.
4. Через ~20 секунд получите адрес вида `https://random-name-123.netlify.app`.

Можно переименовать адрес: Site settings → Change site name → `karta-066u.netlify.app`.
Позже можно привязать аккаунт, чтобы сайт не удалился через сутки.

Альтернатива тем же способом: https://static.app , https://tiiny.host

---

## Вариант 3. GitHub Pages — навсегда, с автопубликацией

Проект уже содержит готовый workflow `.github/workflows/deploy.yml` — он сам собирает
и публикует сайт при каждом пуше.

1. Зарегистрируйтесь на https://github.com (бесплатно, работает из России).
2. Нажмите **New repository**, имя например `karta-066u`, вид **Public**, создайте.
3. Загрузите код проекта. Через веб-интерфейс — кнопка *uploading an existing file*,
   или через git:
   ```
   git init
   git add .
   git commit -m "форма 066/у"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/karta-066u.git
   git push -u origin main
   ```
4. В репозитории: **Settings → Pages → Build and deployment → Source** выберите
   **GitHub Actions**.
5. Вкладка **Actions** — дождитесь зелёной галочки у «Deploy to GitHub Pages».
6. Сайт: `https://ВАШ_ЛОГИН.github.io/karta-066u/`

Дальше достаточно пушить изменения — сайт обновится автоматически.

> Важно: внешний ключ (заголовки, кнопки, подсказки) не содержит ничего, кроме текста
> бланка, — персональные данные пациентов никуда не отправляются.

## Альтернативные бесплатные площадки (доступны из РФ)

| Площадка | Домен | Особенности |
|---|---|---|
| **Cloudflare Pages** | `*.pages.dev` | подключить репозиторий GitHub; очень быстрый |
| **GitLab Pages** | `*.gitlab.io` | если удобнее GitLab |
| **Vercel** | `*.vercel.app` | импорт из GitHub в два клика |
| **GitHub Pages** | `*.github.io` | самый надёжный долгосрочный вариант |
| **Netlify** | `*.netlify.app` | самый простой старт (Drop) |

Настройка Cloudflare Pages: Create project → Connect Git → build command `npm run build`,
output directory `dist`.

## Российские хостинги

Бесплатного «навсегда» виртуального хостинга в РФ практически нет, но есть нюансы:

- **Beget, Timeweb, reg.ru, Sprinthost** — платный хостинг от ~150–300 ₽/мес.
  Загружаете один файл `dist/index.html` в корень сайта по FTP — и всё работает.
  Оплата российской картой, домен `.ru` в комплекте или отдельно (~200 ₽/год).
- **Yandex Cloud / Cloud.ru** — есть гранты для новых пользователей и для медицинских
  организаций; статический сайт можно разместить в Object Storage как бакет-сайт.
  Подходит, если требуется размещение на российской инфраструктуре.

Порядок действий для любого обычного хостинга: собрать `npm run build` →
загрузить содержимое папки `dist` в корневой каталог сайта → готово.

## Если что-то не открывается

- **Страница белая.** Вы открыли `index.html` не из папки `dist`, либо загрузили только
  часть файлов. Нужен именно собранный файл из `dist` (он один и содержит всё).
- **Печатается не 2 страницы.** В диалоге печати отключите «Поля и колонтитулы» /
  выберите «Поля: по умолчанию», масштаб — 100%.
- **Данные пропали.** Данные хранятся в браузере (localStorage) на том устройстве, где
  вы работали. Перенос на другой компьютер — кнопкой **«💾 JSON»**, затем **«📂 Открыть»**.
- **Нужен доступ с планшета в процедурном кабинете.** Используйте «📦 Офлайн-копию»
  и открывайте файл локально — так не зависит от Wi-Fi.

## Что уже настроено в проекте

- `vite.config.ts` — плагин `vite-plugin-singlefile`: сборка в один HTML.
- `.github/workflows/deploy.yml` — автопубликация на GitHub Pages.
- `netlify.toml` — настройки сборки для Netlify (папка `dist`).
- Никаких внешних запросов приложение не делает: без аналитики, без CDN, без шрифтов
  из сети — поэтому работает за любым firewall.
