# Статистическая карта 066/у

Приложение для заполнения учётной формы № 066/у и экспорта бланка.

## 🚀 Быстрый старт (ничего устанавливать не нужно)

Готовое приложение уже лежит в папке **`docs/`** — это один файл `index.html`,
в котором внутри уже есть вся программа.

**Открыть на своём компьютере:**
1. Скачайте репозиторий (Code → Download ZIP).
2. Распакуйте.
3. Откройте файл **`docs/index.html`** двойным щелчком.

Всё. Работает без интернета.

---

## ⚠️ Не открывайте `index.html` из корня

В проекте два файла с одинаковым именем:

| Путь | Что это | Работает в браузере |
|---|---|---|
| `index.html` (корень) | исходный код для сборки | ❌ нет — будет белый экран |
| `docs/index.html` | **готовое приложение** | ✅ да |

Если увидели белый экран — вы открыли не тот файл.

## Публикация на GitHub Pages — самый простой способ

Не требует Node.js, npm и GitHub Actions.

1. Загрузите весь проект в репозиторий (папка `docs` обязательно должна попасть
   в репозиторий — это скрытая проблема: при перетаскивании файлов в браузере
   следите, чтобы папка `docs` загрузилась).
2. В репозитории: **Settings → Pages**.
3. **Build and deployment → Source:** `Deploy from a branch`.
4. **Branch:** `main`, **Folder:** `/docs`. Нажмите **Save**.
5. Через минуту приложение доступно по адресу
   `https://ЛОГИН.github.io/ИМЯ_РЕПО/`

### Почему именно `/docs`
GitHub Pages умеет публиковать содержимое папки `docs` напрямую, без сборки.
Поэтому в репозитории лежит уже собранный файл — сборка на вашей стороне не нужна.

---

## Альтернатива: GitHub Actions

В репозитории есть `.github/workflows/deploy.yml` — он сам собирает проект и
публикует. Тогда в **Settings → Pages → Source** выберите **GitHub Actions**.
Оба способа работают; используйте любой один.

## Если нужно пересобрать самостоятельно

Команды выполняются **на вашем компьютере** в терминале:
- Windows: правый клик в папке проекта → «Открыть в терминале» / PowerShell;
- macOS: Программы → Утилиты → Терминал, затем `cd` в папку проекта.

Нужен установленный [Node.js](https://nodejs.org) (версия 20 или новее).

```
npm install
npm run build
```

После сборки скопируйте полученный файл в папку `docs`, чтобы обновить
публикуемую версию:

```
cp dist/index.html docs/index.html
```

## Экспорт данных

- **Печать / PDF** — бланк на двух листах А4;
- **HTML** — вёрстка бланка отдельным файлом;
- **Word** — редактируемый документ;
- **JSON** — перенос данных между компьютерами;
- **Офлайн-копия** — всё приложение одним файлом для работы без интернета.

Данные хранятся только в браузере на том компьютере, где велся ввод, и никуда
не отправляются.
